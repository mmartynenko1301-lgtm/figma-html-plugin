# Banner Export — Figma-плагін

Експортує фрейм банера з Figma у HTML5 ZIP для рекламних мереж. Шарам можна додавати анімації появи, циклу та hover. План: https://claude.ai/artifact/9MWjdv2ZQis4LJDQQm558M

## Фаза 0 (прототип)

- Фрейми, групи, прямокутники й еліпси із суцільною заливкою, обведенням, тінями та радіусами відтворюються CSS.
- Текст відтворюється HTML з усіма стилями сегментів; шрифти підключаються з Google Fonts.
- Вектори експортуються як SVG. Картинки, маски, градієнти й складні ефекти експортуються як PNG @2x. Фон контейнера з градієнтом або картинкою стає окремою картинкою, а дочірні шари лишаються окремими.
- ZIP містить `index.html` із `<meta name="ad.size">` і `clickTag`, а також папку `img/`. Однакові картинки записуються один раз.

## Фаза 1 (анімації)

- Панель шарів вибраного фрейму синхронізована з виділенням на полотні.
- На кожен шар можна задати три анімації: **поява** (проявлення, виїзд з чотирьох боків, збільшення, зменшення), **цикл** (пульсація, тремтіння, підстрибування, плавання, похитування) і **hover** (збільшення, зменшення, підйом, яскравість; при наведенні на банер або на шар).
- Налаштування зберігаються у файлі Figma (`pluginData`): `anim` на шарах, `banner` на фреймі.
- Живе превʼю оновлюється одразу після змін, кнопка «Програти» запускає анімацію заново.
- Профілі мереж: Google Ads, Google Ad Manager / CM360 / DV360, IAB, без обмежень. Цикли обрізаються під ліміт тривалості мережі; вага, кількість файлів і розмір банера перевіряються після експорту.
- Backup JPG: тоді завантажується `*_export.zip` із ZIP для мережі та JPG (структура описана у фазі 2a).
- Анімації стартують після завантаження картинок і шрифтів і вимикаються при `prefers-reduced-motion`.

## Фаза 2a (пакетний експорт і мережі)

- Якщо виділено кілька фреймів, кнопка «Експортувати всі» збирає їх в один `*_export.zip`: `preview.html` з усіма банерами поруч, `zips/` для завантаження в мережу, `backups/` з JPG і `preview/` з розпакованими банерами. Мережа, посилання і backup беруться з поточного фрейму, анімації кожен фрейм має свої.
- Нові мережі: **Adform** (`manifest.json`, клік через `clickTAG` з `Adform.DHTML.js`) і **Admixer** (фрагмент `body.html` для HTML5 API Admixer).
- Нові пресети: поява **шторкою** (зліва направо, знизу вгору), **текст по словах** і **по літерах** із кроком затримки, цикл **відблиск** і анімація **зникнення** (проявлення, виїзд у чотири боки, віддалення) у заданий момент.
- Анімацію шару можна скопіювати і вставити на всі виділені шари.

## Фаза 2b (вага, таймлайн, ключові кадри, пресети)

- **Автостиснення:** якщо ZIP не вміщується в ліміт мережі, плагін по черзі пробує сильніше стиснення картинок і зупиняється на першому, що вміщується. Рівні: JPEG 90% @2x, JPEG 82% @1.5x, JPEG 75% @1x, JPEG 60% @1x. JPEG отримують лише непрозорі картинки, а прозорі PNG тільки зменшуються. SVG очищується від коментарів і зайвих переносів завжди. Вимикається в налаштуваннях експорту.
- **Таймлайн** над списком шарів показує появу, власну анімацію, цикл і зникнення кожного шару на спільній шкалі часу. Смужку можна перетягнути, щоб змінити час старту. Курсор відтворення стартує разом із превʼю.
- **Власні ключові кадри:** таблиця кадрів (%, X, Y, масштаб, поворот, прозорість), тривалість циклу, easing і кількість повторів (0 означає повтор до ліміту мережі).
- **Пресети:** анімацію шару можна зберегти як пресет у файлі Figma (його бачить уся команда) або на своєму компʼютері, застосувати до виділених шарів і передати в інший файл через JSON.

## Оновлений інтерфейс

- Превʼю, кнопки «Програти»/«Оновити», тривалість і вкладки закріплені вгорі, кнопка експорту — внизу; прокручується лише вміст вкладки.
- Вкладки: **Анімація** (шари разом із таймлайном і редактор), **Пресети**, **Експорт** (з результатом останнього експорту й шкалою ваги).
- Редактор показує картки лише для доданих анімацій; решту додають кнопками «+ Поява», «+ Цикл» тощо. Кольори карток збігаються з кольорами смужок на таймлайні.
- Числові поля можна змінювати, перетягуючи їхній підпис ліворуч або праворуч.
- Шість стартових пресетів для заголовка, кнопки, логотипа і фону.
- Розмір вікна плагіна змінюється кутиком справа внизу і запамʼятовується.

## Інтерфейс v2 (темний)

- Вікно 1120×720: зліва великий вьюпорт із превʼю, під ним таймлайн, справа панель властивостей із вкладками «Анімація», «Пресети», «Експорт» і кнопкою експорту внизу.
- Превʼю масштабується під вьюпорт (Fit) або показується в 50/100/200%. Унизу вьюпорта видно тривалість відносно ліміту, вагу останнього експорту і мережу.
- На шкалі таймлайну можна тягнути курсор: превʼю ставиться на паузу в цьому моменті. «Програти» запускає анімацію знову.
- Висоту таймлайну можна змінити, потягнувши межу над ним.
- Темна тема в стилі референсів: сірі кнопки з тонкою обводкою, картки, вдавлені поля.

## Англійська версія

- Перемикач **UA / EN** у верхній панелі (і на стартовому екрані) змінює мову всього інтерфейсу, попереджень, описів мереж, назв стартових пресетів і кнопки в `preview.html`. Вибір запамʼятовується для користувача.
- У коді кожен текст записано як `t('українською', 'in English')` (`src/shared/i18n.ts`), тож обидві версії лежать поруч.

## Анімовані GIF

- Якщо верхня заливка прямокутника або фрейму — GIF, у банер іде оригінальний файл, тож анімація зберігається. Режими Fill/Crop стають `object-fit: cover`, Fit — `contain`. Кути, обведення, тіні й суцільні заливки під GIF малюються CSS.
- GIF не перестискається автоматично (canvas залишив би лише перший кадр); великий файл дає попередження.
- Якщо шар з GIF під маскою, з ефектом, який CSS не відтворює, або вкладений у растрований шар, він експортується статичною картинкою.

## Як запустити у Figma

1. `npm install`
2. `npm run build` (або `npm run watch` під час розробки)
3. У Figma Desktop: Plugins → Development → Import plugin from manifest… → вибрати `manifest.json` з цієї папки.
4. Виділити фрейм банера → Plugins → Development → Banner Export.

## Розробка

- `src/main` — код у пісочниці Figma: читає шари і будує проміжну модель (`src/shared/ir.ts`).
- `src/core` — генератор HTML/CSS і анімацій (`animate.ts`) та профілі мереж (`networks.ts`), без залежності від Figma.
- `src/ui` — інтерфейс плагіна на Preact: шари, редактор анімацій, превʼю і збирання ZIP.
- `src/shared/anim.ts` — модель анімацій і налаштувань банера.
- `npm test` — тести генератора, `npm run typecheck` — перевірка типів.
